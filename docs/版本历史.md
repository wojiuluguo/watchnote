## 四、当前已知问题（最终版要解决）

1. 圆环视觉上仍被用户认为"没变大"（需要按 480×480 实际尺寸验证）；
2. EdgeButton 出现/消失动画在部分页面不明显（内容不滚动时一直显示）；
3. 3.0 重写导致官方组件丢失，3.x 只是补丁，动画/弹窗/返回体验不如 2.5；
4. 设置子页是否要恢复"弹窗后窗"形式（v2.5 是 Dialog 浮层）；
5. 满血/性能模式差异感知弱；
6. 2.5 的完整性 vs 3.x 的流畅性无法兼得——最终版要用 2.5 架构 + release 重新打包解决。
