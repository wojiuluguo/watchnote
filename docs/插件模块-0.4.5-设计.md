# 插件模块 0.4.5 设计（布局 + 两级画布 + 联网 + 主页面）

> 状态：设计已定，实现中。APP 版本 4.1.34 / versionCode 143；`PluginApi.API_LEVEL = 5`，`MODULE_VERSION = "0.4.5"`。

## 一、这一版交付什么

| # | 能力 | 一句话 |
|---|---|---|
| 1 | 布局容器树 | 页面是一棵节点树，容器自己排：横排/竖排/叠放/分组/网格/滚动 |
| 2 | 两级画布 | 元素画布（画一个按钮）与整页画布（全屏重画） |
| 3 | 联网渠道 | `host.net()`，GET/POST，只走 APP 这一条通道 |
| 4 | 插件主页面 | 插件能占一整页，指示栏封顶 6 格 |

## 二、统一模型：一切都是节点

一个插件页面 = 一棵节点树。节点分四类：

| 类别 | 节点 | 说明 |
|---|---|---|
| 容器 | `row` / `column` / `box`（叠放）/ `group`（带框分组）/ `grid(cols)` / `scroll` | 决定子节点怎么摆 |
| 官方行 | 现有 18 种（section / note / hero / item / progress / ring / stepper / chips / colorCard / timeCard / toggle / divider / space / empty / bars / shape / stat / button） | 宿主渲染，风格统一 |
| 画布 | `canvas` | 插件自绘 |
| 第三方组件 | 由前置模块导出、别的插件调用 | 外形上是节点，内部仍由它自己的布局/画布实现 |

每个节点都有同一组位置属性：

```
parent   属于哪个容器（默认当前容器）
index    第几个（默认追加到末尾）
weight   自动排布时占多少份（默认 0 = 按内容）
align    在容器内的对齐
x y w h  坐标排布时用（单位 dp 或 0~1 归一化）
margin padding
```

## 三、排布：自动与坐标两条路，可以混用

| 方式 | 怎么写 | 用在哪 |
|---|---|---|
| 自动流式 | `page.column { row(...); note(...); canvas(...) }` 从上往下/从左往右 | 绝大多数页面 |
| 显式序号 | `add(parent, node, index = 2)` | 想插到第几个、想改顺序 |
| 坐标 | 容器 `layout = ABSOLUTE`，子节点写 `x/y/w/h` | 叠放、角标、仪表盘刻度 |

一个页面可以混：外层 `column` 自动流，中间某个 `box` 用坐标把标题叠在图上，下面再来一段官方行。

## 四、两级画布（关键）

### A. 元素画布 `canvas(heightDp)`

- 就是一个节点：可以画一块按钮、一个环形图、一个小控件。
- 画布内部可声明命中区（hit region），点中 → 回调 `actionId` → 调任何宿主 API（打开页面、写待办、`net` 请求……）。
- 也就是她说的「画一个按钮，就这样进入 API」。

### B. 整页画布 `page.canvas(FILL)`

- 作为页面根节点，占满可视区，插件全屏重画。
- 宿主仍给：圆屏安全区的宽高、可选的顶栏（标题/返回，可关）、崩溃与超时护栏。
- 也就是「画一整个页面，进入整个画面的 API」；插件也可以只给自己用，不导出。

### C. 两者关系

- 同一个画笔对象，区别只有尺寸和「外壳由谁画」。
- 画布只画像素；要官方控件就直接放官方行。所以一页可以是：官方行 → 画布 → 官方行 → 第三方组件，任意混排。
- 没有 `mode = 画布` 的开关，不存在「选了画布就拿不到 API」。

## 五、画笔 API

坐标：默认归一化 `0~1`（换表盘不变形），也可写 dp。

| 类 | 原语 |
|---|---|
| 形状 | `clear` `rect` `roundRect` `circle` `line` `path` `arc` |
| 文字 | `text`（字号 dp、最大宽度、单行/换行、对齐） |
| 图片 | `image`（插件资源或内置图标名） |
| 变换 | `clip` `translate` `rotate` `scale` `alpha` |
| 颜色 | `#RRGGBB` / `#AARRGGBB` / 主题 token（text / primary / surface / muted） |

事件：`tap(x,y)` / `longPress(x,y)` / `drag(dx,dy)`，回调里可以调宿主 API 与第三方 API，结果回来 `invalidate()` 重绘。

## 六、防 bug（她最担心的部分）

1. **每次绘制包 try/catch**：画布抛错只画一块占位，不崩页面；同一页连续崩 3 次自动停用该页。
2. **参数全部夹取**：负数尺寸→0，NaN/Infinity→默认值，非法颜色→主题色，越界坐标→裁剪不报错。
3. **上限只兜底不裁剪能力**：树深 ≤ 16、每页节点 ≤ 200、每帧绘制指令 ≤ 4000；单次 `onDraw` 超 8ms 记一次，连续 3 次降级为静态帧。
4. **成环检测**：`parent` 指向自己或形成环 → 拒绝并报错，不挂死。
5. **绘制不阻塞**：`onDraw` 里禁止网络/磁盘；要发请求用回调或异步，回来再 `invalidate()`。
6. **未知节点/未知 actionId**：忽略 + 记日志，不抛异常。
7. **向后兼容**：老页面（18 行声明式）渲染路径完全不动；`minApi < 5` 的插件装不上。

## 七、为什么是 0.4.5，不是 0.5

0.5 的要求里有一条这一版没做到：**插件要能改腕记自己的页面**——官方页面的布置、按钮样式都能被插件改。

0.4.5 先把能做好的四件事给出来：布局、画布、联网、主页面。等官方页面也能被插件修改了，这一版才叫 0.5。
